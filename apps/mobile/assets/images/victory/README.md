## Base prompt

Create a single transparent PNG game UI victory character asset for Flap Fit. Reference images establish the exact existing yellow bird identity and polished cartoon rendering style. Show this same golden yellow bird facing directly FRONT, proudly doing a classic DOUBLE FRONT BICEPS FLEX: both upper arms extended sideways near shoulder height, elbows bent 90 degrees, forearms up, closed feather fists on either side of its head. No dumbbells, no weights, no props, no trophy. Full body visible including orange bird feet; confident joyful grin, familiar crest, large brown eyes, orange beak and feet, dark clean outlines, glossy shaded feather muscles. Symmetrical readable silhouette and strong biceps. This is a cheerful short victory pose mascot, not a new human character. Keep recognizable same bird face. Square canvas, bird fills 85% of frame with equal transparent margin and no clipping of fists/feet. Truly transparent background, no ground, no shadow backdrop, no text or badges.

References: ../exercises/biceps.png and ../evolution/sunny/stage-10.png.

## Recolor prompt template

Edit this exact transparent Flap Fit victory bird asset into its {skin} player-color variant. Change ONLY the golden/yellow feather and muscle color regions to {palette}. Preserve identical front double-biceps flex pose, proportions, scale, framing, face, silhouette, clean dark outlines, texture, lighting and transparency. Eyes remain white with brown pupils, beak and feet remain orange, inner mouth remains red. No yellow feather regions remain. No additional objects, no text, no backdrop. Keep all anatomy and composition locked to the reference. This is one recolor of the same bird, not a redesigned character.

Reference for all recolors: sunny-flex.png.

- ruby: rich ruby red feathers, lighter coral-red belly, darker crimson feather shadows
- sky: bright sky-blue feathers, light icy blue belly, deeper blue feather shadows
- kiwi: bright leaf-green feathers, light lime-green belly, darker green feather shadows
- violet: violet-purple feathers, lighter lavender belly, deeper purple feather shadows
- onyx: charcoal-black feathers, slate-gray belly, silver-gray highlights so all muscles remain readable; black bird not navy blue
